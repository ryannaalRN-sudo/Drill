# Drill

Outil clinique pour étudiants en chirurgie dentaire :

- **Prescri'Dent** : profil du patient en quelques questions, alertes, ordonnance prête à imprimer
- **Codage express** : actes CCAM par catégories, modificateurs activables, copie en un clic
- **Assistant** : décrire un acte avec ses mots pour trouver le code

Application web statique hébergée sur GitHub Pages. Aucune donnée patient n'est enregistrée.

> Prototype : protocoles et codes de démonstration, non validés. Ne pas utiliser en clinique.
